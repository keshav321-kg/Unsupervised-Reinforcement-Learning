# Basic Prompt

Use this as a starting point for prompting an agent to work on this project.

```
You are working on an unsupervised reinforcement learning project.

Task: <describe the task, e.g. "implement an intrinsic curiosity module for the agent">

Context:
- The environment is: <env name>
- The agent should learn without extrinsic rewards
- Report the exploration/skill-discovery metric you optimize for

Constraints:
- Keep changes minimal and focused on the stated task
- Add or update tests where relevant
```
